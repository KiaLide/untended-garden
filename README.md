# 無人照看的花園 · The Untended Garden

一座依日期自己生長的花園。每天午夜過後，花園會依當天日期長出新的一片植物；同一天裡每個人看到的都一樣。

- 單一檔案 `index.html`，沒有伺服器、資料庫或建置步驟。
- 植物全由日期算出（以日期字串為種子的偽隨機數），所以不需要儲存任何資料。
- 唯一的外部資源是 Google Fonts，載不到時會退回系統字型，不影響運作。

網址：https://kialide.github.io/untended-garden/

也可以直接用瀏覽器打開 `index.html`，或丟到任何靜態主機（Cloudflare Pages、Netlify）。

種下於 2026-10-06。
